# Pennsylvania ZIP lookup

Source: GeoNames US postal-code dataset, bundled in zipcodes-us 1.2.0 (https://www.npmjs.com/package/zipcodes-us). Retrieved October 9, 2026. Original dataset: https://download.geonames.org/export/zip/

License: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/ . GeoNames attribution: https://www.geonames.org/ .

Only unique five-digit ZIPs with state code PA were extracted. Existing routine coverage lists take precedence. A missing ZIP is shown as not recognized as Pennsylvania, rather than asserted to be out of state. This is a routing snapshot, not USPS address validation; refresh the dataset when a newly assigned ZIP is encountered. No new runtime dependency or geographic coordinates were added.
